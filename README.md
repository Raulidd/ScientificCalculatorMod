# Scientific Calculator Mod for Spaceflight Simulator

A functional scientific calculator integrated directly into **Spaceflight Simulator (SFS 1.6.0)**. Perform quick and complex mathematical calculations without alt-tabbing or leaving the game.

---

##  Features

* **In-Game Interface:** Accessible, non-intrusive UI built specifically for SFS 1.6.0.
* **Math Evaluator Engine:** Built-in custom expression parser (`MathEvaluator.cs`) for handling multi-step equations, scientific functions, and standard arithmetic operations.
* **Lightweight & Fast:** High performance with zero impact on flight frame rates, if you have a bad pc graphs may destroy your fps but anyways it has a settings button.

---

##  Installation

1. Ensure you have **Spaceflight Simulator +1.6.0.0**.
2. Download the latest release package.
3. Extract `ScientificCalculatorMod.zip` and place the file on "C:\Program Files (x86)\Steam\steamapps\common\Spaceflight Simulator\Spaceflight Simulator Game\Mods" or something like that
